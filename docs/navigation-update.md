# تحديث الرجوع والتنقل — 1.0.2

تاريخ التسليم: 12 أكتوبر 2026. الحزمة: `com.azkar.almumin`، الإصدار: `1.0.2`، رقم البناء: `3`. أكد المالك أن آخر رقم مستخدم هو `2`.

## التغييرات

- مستمع واحد لزر رجوع Android يقرأ المسار وحالة الواجهة الحالية: يغلق نوافذ Layout والقائمة الجانبية أولاً، ثم يستدعي `CapacitorApp.exitApp()` عند الرئيسية. داخل الأقسام يرجع عبر سجل الموجّه، أو إلى الرئيسية عند الفتح المباشر دون سجل.
- القائمة السفلية تُركّب فقط عندما يكون المسار `/`؛ تختفي مباشرة داخل جميع الأقسام وتعود عند الرئيسية.
- حجز مساحة أسفل محتوى الأقسام: 16 بكسلاً للصفحات العريضة، و40 بكسلاً للصفحات العادية، مع المنطقة الآمنة للنظام. تُحجز أيضاً داخل المساحة المحددة للقارئ ذي التمرير الداخلي، وأزيل احتساب المنطقة الآمنة مرتين في قارئ القرآن.
- تحديث سكربت تصوير الجهاز ليعود إلى الرئيسية قبل اختيار القسم التالي، وتصحيح اسم Activity المؤهل بالكامل.
- الأصل محفوظ في الأرشيف خارج المصدر، ونقطة Git السابقة `299e8ee` محفوظة في `backup/before-navigation-fix-20261012`. فرع العمل: `fix/home-back-and-section-navigation`.

اختبار المتصفح غطى عروض 320 و360 و412 و768 بكسلاً: الرئيسية، الأذكار وقارئ أذكار الصباح، القرآن وقارئ سورة، الإعدادات والأدعية. تحقق من إخفاء القائمة وإعادتها، غياب التجاوز الأفقي، الوصول إلى آخر المحتوى وإعدادات الأذكار وزر الحفظ، ومن زيادة المسافة عند محاكاة منطقة آمنة سفلية 24 بكسلاً.

ثُبّت Debug على محاكي Android 16 / API 36، وظهرت الرئيسية في المحاولة الثانية، لكن نافذة `System UI isn't responding` اعترضت زر الرجوع. لا توجد حالة Android ناجحة معتمدة، ولا تدل هذه المحاولة على فشل منطق التنقل داخل التطبيق. المحاكي البديل API 30 لم يبدأ بسبب نقص مساحة القرص. يلزم اختبار على هاتف أو محاكي سليم قبل النشر.

## إعادة البناء

يلزم Node.js 22+ وJDK 21 وAndroid SDK 36، مع ملف `android/keystore.properties` ومفتاح المشروع الموجودين محلياً خارج Git. من جذر المصدر بعد تثبيت الاعتماديات:

```powershell
npm run lint
node scripts/test-startup.mjs
npm run build:web
node scripts/test-navigation.mjs
node scripts/sync-android.mjs
java -jar android/gradle/wrapper/gradle-wrapper.jar -p android :app:assembleDebug :app:assembleRelease :app:bundleRelease
```

لإعادة اختبار زر الرجوع على جهاز سليم، ثبّت `android/app/build/outputs/apk/debug/app-debug.apk` ثم شغّل `node scripts/test-navigation-android.mjs <device-serial>`. النسخة الاختبارية منفصلة بالحزمة `com.azkar.almumin.debug` ولا يتطلب السكربت مسح بيانات التطبيق.

في هذه البيئة افتقد `npm ci` ثلاث حزم Windows x64 اختيارية بسبب ملف القفل المرفق. استُعيدت أرشيفاتها عبر `npm pack --ignore-scripts` وفُكّت في `node_modules` بالإصدارات المطابقة دون تغيير اعتماديات المشروع: `@rollup/rollup-win32-x64-msvc@4.61.0` و`@tailwindcss/oxide-win32-x64-msvc@4.3.0` و`lightningcss-win32-x64-msvc@1.32.0`.

بقي المجلد المؤقت `.ai_temp_scripts/avd` (خارج Git وملفات التسليم) لأن فحص الموافقة التلقائي منع حذفه برسالة «محظور بالسياسة». لا يوجد محاكي جديد يعمل منه.

مرجع سلوك الخروج: [Capacitor App API](https://capacitorjs.com/docs/apis/app#exitapp).
